# Usage

To create an ISP service plan:

1. Go to *Sales > Configuration > ISP > ISP Plans*.
2. Click *Create* and fill the product form:
   - **Product Type**: Service
   - Check **ISP Plan**
   - Set **Billing periodicity** (defaults to *Monthly*)
   - Set **Download / Upload speed** in Mbps
   - On the *ISP Plan* page, add any **Additional Products**
3. Save the plan.

To manage additional products independently:

1. Go to *Sales > Configuration > ISP > Additional Products*.
